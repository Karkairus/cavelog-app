CaveLog

Jagua Cave Studios Bug Tracker

CaveLog is a mobile bug tracking application built for Jagua Cave Studios. It allows QA testers, developers, and managers to log, track, and resolve bugs across all of the studio's games.

Features:

  • Secure login with role-based access control
  • Track bugs across multiple games
  • Assign bugs to developers
  • Search and filter bugs
  • Generate bug reports

Installation Instructions:

This is an Android application (.apk). To install:

  1. Download the APK file using the button below
  2. On your Android device, go to Settings and enable "Install from Unknown Sources"
  3. Open the downloaded APK file and follow the installation prompts
